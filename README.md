# Chart Exploration

A collaborative data-visualization exercise built with D3.js and Colorbrewer, where each contributor built their own set of charts.

## Contributors

- Bini
- Dhairya (Arya)
- Mira

Each contributor's charts live in their own folder (`Bini_Project-2_charts`, `Dhairya_Project-2_charts`, `Mira_Project-2_charts`).

## Tech Stack

- D3.js / `colorbrewer.js`
- HTML / CSS
